Personas
========

The users the product is designed for. One section per persona. Keep them
evidence-based (from interviews/analytics), not invented. Referenced by user
flows and screen specs.

## Persona: End User (account holder)

| Field | Value |
|-------|-------|
| Persona ID | PER-ID-001 |
| Role / Title | End User (account holder) |
| Goals | Sign in quickly without managing a password |
| Pain points | Forgotten passwords; password reuse across sites |
| Context (device, environment, frequency) | Desktop and mobile browser; signs in a few times per week |
| Access level (roles / permissions) | Standard user |
| Key tasks (UC IDs) | UC-ID-Login |
