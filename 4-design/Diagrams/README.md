Diagrams
========

Phase 4 diagrams: ERD, sequence, state, and architecture. Keep PlantUML sources
here (entity-relationship diagrams go under `ERD/`). The attribute-level schema
lives in `../Entities.md`, `../DDTs.md`, and each `../../modules/<Module>/Entities.md`.

Note: most LLMs get diagram logic wrong. A generated diagram is a prototype -
go over each one and assert its correctness before you rely on it.
