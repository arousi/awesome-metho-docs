Documentation Skill (moved)
===========================

The documentation skill now lives under `skills/`, split into one decoupled skill per lifecycle phase:

- `doc-planning` - Phase 0 Planning (`PM/` charter)
- `doc-analysis` - Phase 1 Analysis (`Analysis/Analysis.md`)
- `doc-requirements` - Phase 2 Requirements (FR/UC/NFR)
- `doc-design` - Phase 3 Design and Modeling (Entities + Diagrams)
- `doc-implementation` - Phase 4 Implementation traceability
- `doc-testing` - Phase 5 Testing (`Testing/TestCases.md`)

Start at `skills/document-software-project/SKILL.md` (the umbrella orchestrator) and see `LIFECYCLE.md` for the phase model.
