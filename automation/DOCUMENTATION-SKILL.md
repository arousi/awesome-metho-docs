Documentation Skill (moved)
===========================

The documentation skill now lives under `.claude/skills/`, split into one decoupled skill per lifecycle phase:

- `doc-planning` - Phase 0 Planning (`0-planning/` charter)
- `doc-analysis` - Phase 1 Analysis (`1-analysis/Analysis.md`)
- `doc-requirements` - Phase 2 Requirements (FR/UC/NFR)
- `doc-ux` - Phase 3 UX (`3-ux/Screens.md`)
- `doc-design` - Phase 4 Design and Modeling (Entities + Diagrams)
- `doc-implementation` - Phase 5 Implementation traceability
- `doc-testing` - Phase 6 Testing (`6-testing/TestCases.md`)

Start at `.claude/skills/document-software-project/SKILL.md` (the umbrella orchestrator) and see `LIFECYCLE.md` for the phase model.
